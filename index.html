CommitCraft
Google Gemma 4 · Web · CLI · Agent Skill

"fix stuff" is not a commit message.

Paste your git diff and Gemma 4 writes a Conventional Commit, a PR title and a reviewer-friendly PR description, and flags leftover debug code or missing tests. Same brain in the terminal (git diff --staged | npx commitcraft) and as an Agent Skill for coding agents.

Your diff

Commit message, PR description and review notes appear here.
Lockfiles and binaries are skipped automatically. Nothing is stored.

Use it in your terminal or agent

git clone https://github.com/ayush8620/commitcraft && cd your-project
export GEMINI_API_KEY=your_key
git add -p
git diff --staged | node ../commitcraft/cli.js            # print commit + PR
node ../commitcraft/cli.js --style gitmoji --issue "#42" --commit   # asks, then commits

Coding agents: copy skills/commitcraft/ into your agent's skills folder (Agent Skill open standard, SKILL.md).
